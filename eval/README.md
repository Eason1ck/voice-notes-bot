# Замеры качества и скорости распознавания

Скрипт прогоняет ваши записи через тот же конвейер, что и бот (ffmpeg, затем Whisper),
и считает WER, CER, время обработки и RTF.

## Подготовка набора

Положите записи и эталонные тексты парами с одинаковым именем:

```
eval/dataset/quiet/01.ogg   eval/dataset/quiet/01.txt
eval/dataset/noisy/01.ogg   eval/dataset/noisy/01.txt
```

- Первая вложенная папка (`quiet`, `noisy`) считается условием записи, по ним строится сводка.
- Текст для чтения: `eval/phrases.txt`. Эталон в `.txt` должен совпадать с тем, что реально сказано.
- Лучше без цифр: числа не переводятся в слова, и «5» против «пять» будет ошибкой.
- Получить запись: Telegram Desktop, правая кнопка на голосовом, «Сохранить как» (.ogg),
  либо Диктофон Windows (.m4a). Поддерживаются ogg, oga, opus, wav, mp3, m4a, flac, aac, webm.
- Рекомендуется 10-15 фраз в каждом условии.

## Запуск (из корня проекта)

```
python evaluate.py
python evaluate.py --model base --repeats 3 --label base
python evaluate.py --model small --device cpu --compute-type int8
```

Параметры: `--dataset`, `--output`, `--model`, `--device`, `--compute-type`, `--beam-size`,
`--repeats` (медиана времени по повторам), `--no-warmup`, `--no-vad`, `--normalize-audio`,
`--csv-style excel|plain`, `--label`. Всё, что не указано, берётся из `.env`.

## Результат

В `eval/results/` создаются три файла с меткой времени и моделью в имени:

- `*_samples.csv`: по каждой записи (эталон, результат, WER, CER, время, RTF);
- `*_summary.csv`: сводка по условиям и строка `ALL`;
- `*_meta.json`: модель, параметры, версии библиотек, железо, время загрузки модели.

CSV по умолчанию в формате русского Excel (разделитель `;`, десятичная запятая, UTF-8 с BOM).
Для pandas используйте `--csv-style plain`.

## Метрики

- WER = (замены + удаления + вставки) / число слов эталона. CER считается так же по символам.
- В сводке WER и CER корпусные: суммируются ошибки и длины эталонов, а не средние проценты.
- Нормализация: нижний регистр, «ё» как «е», пунктуация убирается.
- RTF = время распознавания / длительность аудио. Меньше 1 значит быстрее реального времени.
- Время распознавания не включает загрузку модели (она в `meta.json`) и конвертацию (отдельная колонка).
  Перед замерами делается прогревочный прогон, он в статистику не входит.
- Запись, которую не удалось обработать, считается как пустой результат (WER = 100%)
  и не участвует в статистике времени.
- `ok` означает, что результат осмысленный по тем же правилам, что и в боте.

## Ограничения

Малый набор и один диктор дают оценку для конкретных условий, а не общую точность модели.
Время зависит от железа и нагрузки: укажите процессор и ОЗУ в записке.
