# voice-notes-bot

Telegram-бот, который превращает голосовые сообщения в текст. Распознавание идёт локально
моделью Whisper (библиотека faster-whisper), голос не отправляется сторонним сервисам.
Это модуль 1 системы ведения персональных заметок: бот получает голосовое, возвращает текст
и готов передавать его дальше (суммаризация, заголовок, темы).

## Что нужно установить

| Что | Зачем | Как |
|---|---|---|
| Python 3.10 или новее | запуск бота | python.org |
| ffmpeg | конвертация голосовых Telegram (OGG/Opus) в WAV | Windows: `winget install Gyan.FFmpeg`; macOS: `brew install ffmpeg`; Ubuntu: `sudo apt install ffmpeg` |
| Токен бота | доступ к Telegram | написать @BotFather, команда `/newbot` |
| Библиотеки Python | aiogram, faster-whisper | `pip install -r requirements.txt` |

После установки ffmpeg откройте новый терминал и проверьте: `ffmpeg -version`.

## Быстрый старт

```
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux и macOS
pip install -r requirements-dev.txt
copy .env.example .env          # Linux и macOS: cp .env.example .env
```

Откройте `.env` и впишите токен от BotFather в `BOT_TOKEN`. Затем:

```
python -m bot.main
```

При первом запуске faster-whisper скачает выбранную модель (нужен интернет, размер зависит
от модели), поэтому старт займёт время. Дальше откройте бота в Telegram, нажмите `/start` и
отправьте голосовое сообщение.

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | пусто | токен от @BotFather (обязательно) |
| `WHISPER_MODEL` | `small` | `tiny`, `base`, `small`, `medium`, `large-v3` |
| `WHISPER_DEVICE` | `cpu` | `cpu` или `cuda` (видеокарта NVIDIA) |
| `WHISPER_COMPUTE_TYPE` | `int8` | для CPU `int8`, для видеокарты `float16` |
| `MAX_DURATION_SEC` | `180` | максимальная длительность голосового |
| `MAX_FILE_MB` | `20` | лимит размера (Bot API не отдаёт файлы больше 20 МБ) |
| `PROCESS_TIMEOUT_SEC` | `180` | лимит времени на распознавание |
| `MAX_CONCURRENT_JOBS` | `1` | сколько записей распознаётся одновременно |
| `NO_SPEECH_THRESHOLD` | `0.6` | порог вероятности «речи нет» для сегмента |
| `LOGPROB_THRESHOLD` | `-1.0` | порог средней лог-вероятности токенов |
| `COMPRESSION_RATIO_THRESHOLD` | `2.4` | порог повторов (признак «галлюцинации») |
| `FFMPEG_PATH` | `ffmpeg` | полный путь к ffmpeg.exe, если он не находится через PATH |
| `NORMALIZE_AUDIO` | `false` | нормализация громкости перед распознаванием |
| `LOG_LEVEL` | `INFO` | уровень журнала |

Пороги и лимиты предварительные: их нужно подобрать по результатам собственных тестов.

### Какую модель выбрать

Чем крупнее модель, тем точнее распознавание и тем дольше обработка. Начните с `small`
на процессоре. Если обработка слишком медленная, попробуйте `base`; если точности мало
и есть видеокарта NVIDIA, поставьте `WHISPER_DEVICE=cuda`, `WHISPER_COMPUTE_TYPE=float16` и
модель покрупнее. Для видеокарты нужны библиотеки NVIDIA CUDA и cuDNN подходящих версий
(см. документацию faster-whisper). Время обработки каждого сообщения пишется в журнал,
так что скорость можно измерить на своём компьютере.

## Как это работает

1. Бот принимает голосовое и проверяет длительность и размер.
2. Скачивает файл во временную папку (она удаляется после обработки).
3. ffmpeg переводит OGG/Opus в WAV 16 кГц моно (при сбое одна повторная попытка).
4. faster-whisper распознаёт речь (язык задан явно, включён VAD-фильтр).
5. Ненадёжные сегменты (нет речи, повторы) отбрасываются.
6. Если текст пуст, слишком короткий или состоит из повторов, пользователь получает подсказку.
7. Текст отправляется пользователю (длинный делится на части по лимиту Telegram).

Ошибки (слишком длинное сообщение, сбой ffmpeg, сбой модели, превышение времени) получают
понятный ответ пользователю; технические подробности пишутся только в журнал.

## Интерфейс для следующего модуля

```python
from bot.stt import transcribe, WhisperTranscriber

text = transcribe("voice.wav")                 # строка с текстом

result = WhisperTranscriber(settings).transcribe("voice.wav")
result.text, result.language, result.segments, result.dropped, result.processing_ms
```

Подключить суммаризацию можно в `bot/handlers.py`, в месте, помеченном комментарием
про модуль 2: туда приходит `result.text`.

## Структура

```
bot/
  main.py        запуск, журнал, загрузка модели
  handlers.py    обработчики Telegram (aiogram 3)
  pipeline.py    конвейер: лимиты, скачивание, конвертация, распознавание
  audio.py       конвертация через ffmpeg
  stt.py         обёртка над faster-whisper, transcribe(path) -> str
  textutils.py   разбиение длинных сообщений, проверка текста
  errors.py      ошибки и тексты для пользователя
  config.py      настройки из .env
eval/            замеры качества и скорости (WER, CER, RTF)
evaluate.py      запуск замеров
run.py           запуск бота
tests/           автотесты (pytest)
```

## Тесты

```
python -m pytest
```

Тесты не требуют токена, Telegram и модели Whisper: распознавание и скачивание
подменяются заглушками. Тесты конвертации используют настоящий ffmpeg и пропускаются,
если его нет.

## Замеры

Скрипт `evaluate.py` считает WER, CER, время и RTF на ваших записях. Подробности и формат
набора данных: `eval/README.md`.

```
python evaluate.py --dataset eval/dataset --model small
```

## Журнал

Файл `logs/bot.log` (с ротацией) и консоль. В журнал пишутся идентификаторы, время,
длительность, ошибки и версия модели; текст и аудио пользователей не записываются.

## Если что-то не работает

- `ffmpeg не найден`: установите ffmpeg и откройте новый терминал (или полностью перезапустите PyCharm).
  Если не помогло, впишите в `.env` полный путь: `FFMPEG_PATH=C:\ffmpeg\bin\ffmpeg.exe`.
- `Не задан BOT_TOKEN`: проверьте файл `.env` в папке проекта.
- Бот молчит: проверьте, что запущен только один экземпляр, и токен верный.
- Долго отвечает: возьмите модель поменьше (`base`) или проверьте, что `WHISPER_DEVICE` соответствует железу.
- Пустой результат на тихой записи: включите `NORMALIZE_AUDIO=true`.
